## 🏗️ Featured Projects

### 🛡️ Evidence Governance Platform (EGP) — Danske Bank · 2026–present

Enterprise platform that turns software-delivery activity into a shared, traceable view of SDLC governance evidence — showing application owners, delivery teams, managers and assurance which checks were observed, what they reported and where the source is. I'm the architect and technical lead.
- Collects pipeline, scanner (SonarQube, Black Duck, CodeQL) and ownership data from GitHub Enterprise and Azure DevOps pipelines across **5,000+ repositories (~6,500 runs/day)**
- Pull-based collection over the GitHub API with discovery, checkpoints and rate-limit budgeting — replacing an earlier per-pipeline push model
- Evidence model with honest metrics: *no evidence is not a pass*; adherence excludes not-applicable rows; full change history
- Web workspace with control dashboards, per-application reports, a rules-based advisor, self-service email reports and **read-only MCP tools** for approved AI assistants
- Enterprise security: corporate SSO (OIDC/PKCE), Kerberos workload identity, secrets outside Git, managed CD with ArgoCD
- Supports **DORA-aligned** ICT change-management and audit traceability; roadmap includes direct scanner APIs, Jira/ServiceNow integration, AI agents and composite health ratings

**Stack:** OpenShift on AWS, TypeScript, .NET, SQL Server, GitHub Enterprise & Actions, Azure DevOps, ArgoCD, MCP, SonarQube, Black Duck, CodeQL

- Full observability stack (Prometheus, Grafana, Loki)

### 📊 Regulatory Compliance Platform (CESOP · MMR-SASK/MAI55 · DORA) — Walletto · 2025

Automated regulatory reporting and resilience programme for a licensed EU electronic money institution:
- **CESOP:** end-to-end EU payment reporting — SQL stored procedures, Python/XML generation with XPath, multi-stage validation and submission; quarterly preparation reduced from days to hours (~90% less manual effort)
- **MMR-SASK / MAI55:** Lithuanian tax authority (VMI) reports built and delivered to production
- **DORA:** ICT risk management, major-incident classification and reporting, operational resilience testing aligned with EBA/ESMA standards
- Reusable compliance architecture: schema validation, data integrity checks, audit trail and automated submission

**Stack:** PostgreSQL, Python, XML/XPath, GitLab CI, Docker
